# analysis

Инструмент для парсинга и анализа логов виртуальной биржи активов.

## Исходные данные

Есть логи двух видов:

**System(requestid):**

- trace
- error

**App(requestid):**

- trace
- error
- journal (человекочитаемая сводка)

## Прототип

Есть прототип штуки, которая умеет:

- парсить логи
- фильтровать
  - по requestid
  - по ошибкам
  - по изменению счёта (купить/продать)

## Модель данных

- **Пользователь** (userid, имя)
- **Вещи**
  - Предмет (assetid, название)
  - Набор (assetid, количество)
  - <!-- Собственность (assetid, userid владельца, количество) -->
  - Таблица предложения (assetid на assetid, userid продавца)
  - Таблица спроса (assetid на assetid, userid покупателя)

### Операция App

**Journal**

- Создать пользователя userid с уставным капиталом от 10 USD и выше
- Удалить пользователя
- Зарегистрировать assetid с ликвидностью от 50 USD
- Удалить assetid (весь asset должен принадлежать пользователю)
- Внести USD для userid (USD, он же доллар США — это тип asset)
- Вывести USD для userid
- Купить asset
- Продать asset

**Trace**

- Соединить с биржей
- Получить данные с биржи
- Локальная проверка корректности (упреждение ошибок в ответе)
- Отправить запрос в биржу
- Получить ответ от биржи

**Error**

- нет asset
- системная ошибка

### Операция System

**Trace**

- Отправить запрос
- Получить ответ

**Error**

- нет сети
- отказано в доступе
